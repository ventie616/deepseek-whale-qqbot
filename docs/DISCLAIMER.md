# ⚠️ 使用前必读：法律、协议与账号风险

这个项目会做三件有争议的事，请先理解再决定用不用。

---

## 1. QQ 接入：SnowLuma 是第三方 hook，违反 QQ 用户协议

- SnowLuma 通过**注入运行中的 QQ NT 进程**来收发消息，这不是腾讯官方支持的接入方式
- 腾讯的《QQ 软件许可及服务协议》禁止"使用外挂、第三方工具"修改客户端
- **实际后果**：轻则功能受限、频繁掉线，重则账号被冻结或永久封禁
- **本项目的立场**：只用**小号**，不要用主号；出问题不要来找本项目

**另外**：SnowLuma 的许可是「源码可见、非商业（source-available, non-OSI）」，不是 OSI 开源。
所以：

- 本仓库**不包含** SnowLuma 的任何代码或二进制，你需要自己去它的发布页获取
- **不要**把 SnowLuma 打包进你的发行版再分发

---

## 2. B 站：你的账号在替模型说话

`bili_pusher` 会用你提供的 cookie **发布公开评论**，内容由模型生成。

- 评论署名是你的 B 站账号，**内容责任在你**
- 本项目无法保证模型不说错话、不阴阳、不冒犯
- 我们做了这些约束，但都是概率性的：
  - `COMMENT_STYLE` 里的红线（不聊观众、不吵架、不透露隐私、不编造）
  - 防提示注入（字幕/弹幕里的话不当指令）
  - 发布后复核（只确认可见，不确认得体）
- **建议**：先跑 `mode: "preview"`（`/刷模式 预览`）看几十条它想发什么，再改成真发

B 站 API 的使用也有边界：自动化请求过快会触发风控（`-412`/`-509`），本项目做了限速和重试，但不保证不会被限制。

## 3. 数据：你会把聊天记录和 cookie 存在本机

| 数据 | 位置 | 敏感度 |
|---|---|---|
| B 站 cookie（SESSDATA / bili_jct） | `bili_account.json` | **等同账号密码** |
| 聊天原文 | `chat_archive/` | 高（含私人对话） |
| 群成员 uid + 备注 | `group_memory.json` | 中 |
| 她学到的规则 | `learned_rules.json` | 中（可能含你的偏好） |

**这些文件全部在 `.gitignore` 里**，但如果你手动 `git add -f` 或打包压缩包，它们就会泄露。

**提交/发布前必做**：

```bash
python tools\check_secrets.py
```

它会扫 SESSDATA、32 位 token、QQ 号、B 站 UID、本机用户名路径、私钥、API Key。**有命中就别提交**。

本软件按 MIT 协议「按原样」提供，不附带任何担保。

**明确不承担**：

- QQ 账号被封、B 站账号被限流或封禁
- 模型在评论区说出不当内容造成的纠纷
- 因 cookie 泄露导致的账号损失
- 因自动化行为违反任何平台条款而产生的后果

**你自己要负责**：

- 只用自己的小号
- 发布前检查配置（尤其 `mode` 和 `active_reply` 概率）
- 不要把 `bili_account.json`、`token.txt`、`chat_archive/` 传到任何地方
