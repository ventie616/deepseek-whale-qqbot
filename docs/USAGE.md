# 使用指南

面向"把它跑起来之后，每天怎么用"的人。装环境看 [`SETUP.md`](SETUP.md)，设计原理看 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

---

## 一、她是谁，会做什么

一个住在 QQ 里的角色，同时干四件事：

| 场景 | 她做什么 |
|---|---|
| **群聊** | 平时潜水，被 @ 或碰上感兴趣的话题才说话；记得住谁是谁、之前聊过什么 |
| **私聊** | 会主动找你（45–90 分钟一次）、早晚问候、你没回会追问一句 |
| **B 站** | 在设定时段自己刷视频、挑值得的、去评论区发一句并 @ 你 |
| **学习** | 你说的"以后别这样"会被记成规则，之后一直遵守 |

她现在的人格是**傲娇鲸鱼娘**：嘴硬、毒舌但黏人，被叫"大肥鱼"会炸毛。人格可以换成任何风格（见第五节）。

## 二、日常怎么跟她说话

### 私聊：随便聊就行

```
你：在吗
她：干嘛
你：无聊
她：……那本鲸陪你无聊一会儿
```

她会记住上下文（最近 24 条原文 + 摘要 + 她上一句），所以可以接着聊，不用每次交代背景。

### 群聊：要 @ 她

```
@机器人 你怎么看这个
@机器人 帮我看看这个视频 BV1xxxxxxxxx
```

**发 B 站 链接她会真的去看**：自动取字幕/画面，然后用自己的话跟你聊这条视频。

群里的"主动插话"概率默认 **10%**（每条没 @ 她的消息掷一次骰子），嫌吵可以调低，见第七节。

### 想让她记住人

在群里说：

```
记住 小明手气很差，抽卡老歪
```

或者她自己会在压缩群摘要时自动抽特征写进人物卡。

### 想让她改说话方式

```
你：以后说话别老用省略号
她：……行吧（啧）
你：跟她说话别那么冲
她：知道了（小声）
```

这些话会被抽成规则入库，`/规则` 能看到。

## 三、全部指令

群聊里 @ 她，私聊直接发。

### B 站（9 条）

| 指令 | 作用 |
|---|---|
| `/刷状态` | 一眼看全：开关、间隔、时段、模式、判据、看图、登录态、今天看了几条 |
| `/刷` | **立刻刷一轮**（挑到值得的会真发评论） |
| `/刷看` | 只挑不发，把结果私聊给你预览（**推荐先试这个**） |
| `/刷开` / `/刷停` | 自动刷开关 |
| `/刷间隔 90` | 间隔 90 分钟（抖动自动设 15） |
| `/刷时段 12-14,16-22` | 改工作时段 |
| `/刷判据 宽` / `/刷判据 严` | 宽松＝情绪价值也算；严格＝拿不准不发 |
| `/刷模式 评论` / `私聊` / `预览` | 发 B站 / 只推 QQ / 只挑 |
| `/刷看图 开` / `关` | 是否抽帧看画面（关掉省 token） |
| `/刷了什么` / `/刷了什么 7` | 看她今天 / 最近 7 天刷了什么 |
| `/刷记录` / `/刷记录 30` | 生成带封面的网页 `reports/browse.html` |
| `/bilicheck` | 立刻检查 B 站登录态 |

### 记忆与规则

| 指令 | 作用 |
|---|---|
| `/规则` | 列出学到的规则（✅ 生效 / ⏳ 待确认） |
| `/学 评论里别用「快过来看」` | 手动教一条 |
| `/确认 r12345` | 启用高风险待确认规则 |
| `/删规则 r12345` | 删掉 |
| `/学状态` | 规则数量、上次整理时间 |

### 黏人与守护

| 指令 | 作用 |
|---|---|
| `/黏人` | 看状态（间隔、今天已发几条、追问几次） |
| `/黏人 开` / `/黏人 关` | 开关主动搭话 |
| `/dtest` | 立刻发一条主动消息（测试用） |
| `/守护状态` | 守护进程是否活着、AstrBot 是否在线 |

## 四、五个常见操作

### 1. 加表情包

```
① 把图丢进 C:\QQBot\sticker_inbox
② 双击 import-stickers.bat（会视觉打标 + 写索引）
```

或者在群里直接发图给她，然后说「保存」——她会先暂存 24 小时，等你发话才入库。

**选图规则**：主情绪 → 群聊排除 risky → 强度（按回复情绪推算）→ 场景加权。约 35% 的回复会配一张。

### 2. 换 B 站 cookie

```powershell
python tools\bili_login_ui.py     # 打开 http://127.0.0.1:8777
```

粘整段 cookie 进第一个框，点「验证并保存」。会先验证登录、顺带验 csrf，不通过不会写文件。

### 3. 调刷 B 站的频率

```powershell
/刷时段 12-14,16-22      # 只在两个时段刷
/刷间隔 180              # 3 小时一轮
/刷判据 严               # 更挑剔
```

改完**不用重启**，下一轮生效。

### 4. 让她记住某个群友

```
@机器人 记住阿饼爱发红包
```

或者在群里聊到某人的特征时，摘要会自动写进人物卡（每人最多 5 条）。

### 5. 教她一条规则

```
@机器人 以后评论里别用感叹号
```

她会抽成规则并生效。规则上限 40 条，45 天没命中的自动下线。

## 五、换人格

人格存在 AstrBot 的 `data_v4.db`，不是文件。两种改法：

**A. 面板改（推荐）**：`http://127.0.0.1:6185` → 人格 → 编辑 → 保存（实时生效）

**B. 改文件后重启**：

```powershell
# 编辑 C:\QQBot-open\examples\persona-whale-girl.txt 后
python tools\set_persona_whale.py
```

人格里建议保留这三段，否则行为会跑偏：

| 段落 | 作用 |
|---|---|
| 【硬性格式】 | 分几条、每条多少字、不用 emoji |
| 【运行环境】 | 群聊/私聊区别、能看图、会查 B 站 |
| 【两套场合】 | QQ 里傲娇、B 站 评论区外放 |

## 六、每天自动发生的事

```
08:30–11:00   她可能发一句早安（每天一次）
12:00–14:00   刷 B 站（每 2 小时一轮，挑到值得的就评论 @ 你）
              └ 有话会私聊你；没挑到就只写日报
16:00–22:00   继续刷 B 站
21:30–23:30   可能发一句睡前的话（每天一次）
全天          私聊主动搭话（45–90 分钟一次，日上限 14 条）
              你 35 分钟没回 → 追问一句（每条只追一次）
09:00         检查 B 站登录态，失效私聊提醒
每 6 小时     检查规则库，超 20 小时就整理（合并相似、下线过期的）
```

**产物在哪**：

| 文件 | 内容 |
|---|---|
| `reports/bili-<日期>.md` | 每日刷 B 站日报（含被跳过的和理由） |
| `reports/browse.html` | 带封面的浏览记录页 |
| `bili_watched.jsonl` | 每一条看过的视频 |
| `bili_memory.json` | 长期视频记忆（评论过的 + 值得的） |
| `chat_archive/` | 聊天原文，保留 30 天 |

## 七、常见调整

| 想要 | 改哪里 |
|---|---|
| 群里别那么爱插话 | AstrBot 面板 → 群聊上下文 → 主动回复概率（默认 0.1） |
| 私聊别那么黏 | `/黏人 关`，或改 `proactive_dm.json` 的 `min_minutes/max_minutes` |
| 评论太频繁 | `/刷间隔 240`，或 `/刷时段 18-22` |
| 她挑得太严（什么都不发） | `/刷判据 宽` |
| 她挑得太松（什么都发） | `/刷判据 严`，或加 `/刷模式 预览` 观察几天 |
| 省 token | `/刷看图 关`（省约 1.8k/条）+ 拉长间隔 |
| 表情包不够用 | 往 `sticker_inbox` 丢图，跑 `import-stickers.bat` |
| 群里记不住人 | 确认 `group_message_max_cnt` 有 24，且摘要没报错 |

## 八、出问题怎么查

| 症状 | 先看这里 |
|---|---|
| 她不回话 | 6185 端口在不在？`/守护状态`；群里是不是没 @ 她 |
| 私聊不主动了 | `/黏人`；时段是不是过了 23:30 |
| B 站 评论失败 | `/bilicheck`；看日志里的错误码（`-101` 缺 SESSDATA，`-111` 缺 bili_jct） |
| 评论发出去但看不到 | 可能被折叠；看她日志的「复核」结果 |
| 群里记不住人 | `group_memory.json` 里有没有那个人；摘要多久没更新 |
| 表情包用了奇怪的图 | 改 `stickers/index.json` 那张的标签 |
| 她答非所问 | 看日志里的「注入」记录，可能注入了不相关的记忆 |
| 服务无声消失 | `logs/watchdog.log`；`schtasks /run /tn QQBotWatchdog` |

**日志位置**：

```
C:\QQBot\astrbot\data\data\logs      AstrBot 完整日志（插件/错误/LLM 调用）
C:\QQBot\logs\watchdog.log           守护进程日志
C:\QQBot\snowluma\logs\              SnowLuma 日志（QQ 收发）
```

## 十、成本参考

| 动作 | 约多少 token |
|---|---|
| 刷新 B 站一条候选（含抽帧） | ~1.8k |
| 生成一条评论 | ~300 |
| 一轮群聊回复（带记忆注入） | ~800–1200 |
| 一次规则抽取 | ~500（只有命中关键词才触发） |
| 一条主动私聊 | ~400 |

按现在配置（每天约 5 轮刷 B 站 + 十几条私聊），一天大概 2–4 万 token 量级。想省：`/刷看图 关` + 拉长间隔。

# 附录：2026-10 新增能力

## 控制台（推荐日常用这个）

双击 `00-控制台.bat` → `http://127.0.0.1:8765/`

- **状态**：心情、今日评论、规则、记忆、表情包、服务在线（8 秒自动刷新）
- **改配置**：刷 B站（间隔/判据/看图/模式/时段）、黏人（开关/间隔/日上限）→ 点保存即写入 json，下一轮生效
- **换心情**：六种心情点一下，或「随机换一个」
- **规则**：逐条查看 + 删除
- **服务**：启动全部 / 停止全部 / 重启 AstrBot / 启动守护 / 打开面板
- **B站**：登录状态（昵称/Lv/UID）、最近 5 条评论（点标题进视频）、打开登录面板、重新自检
- **排障**：马上刷一轮（真发）/ 刷一轮预览（不发）/ 发测试消息 / 看日志 / 看日报

安全：只监听 127.0.0.1；写操作要 `X-Token`（在 `dashboard/.token`），外部网页改不了。

## 心情

她每天有一个心情，78% 是开心/元气。

| 指令 | 作用 |
|---|---|
| `/心情` | 看今天的心情 |
| `/心情 换` | 重掷（一天一次） |

心情只影响语气，不影响人格和记忆；心情不好也不许对主人凶。

## 唱歌

`/唱一段`（随机 12 秒节选，走语音）、`/唱一段 歌名`、`/唱一段 整首`（文件）、`/歌单`。
加歌：`python tools\add_song.py BV号 --name "歌名"`。

## 规则

跟她说「以后…」「别…」就会自动学成规则，注入之后的对话。

| 指令 | 作用 |
|---|---|
| `/规则` | 列出所有规则 |
| `/删规则 r12345` | 删掉一条 |
| `/确认 r12345` | 启用高风险待确认规则 |

45 天没命中的规则会自动下线。
