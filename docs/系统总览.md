# 系统总览（2026-10-29 · v3.0）

> 一个住在 Windows 上的 QQ 机器人：AstrBot 做框架，SnowLuma 接 QQ，DeepSeek 当脑子，
> 声音和生图跑在本机 WSL 的 GPU 上，人格叫「鲸鱼娘」。

---

## 一、一句话架构

```
QQ
  ↓ OneBot v11
SnowLuma（协议端，3000 / 后台 5099）
  ↓ 反向 WS
AstrBot（框架，6185）
  ├─ 27 个插件 / 32 个 LLM 工具
  ├─ 人格（persona\whale-girl.md）
  ├─ DeepSeek：v4-pro 聊天 / flash 干活（可一键全切 flash）
  └─ 控制台（8765）+ 知识图谱 + 声音调音台
  ↓
本机 WSL（D:\wsl\Ubuntu-22.04，GPU 直通）
  ├─ 声音服务 9880：CosyVoice3 说话 / RVC 换声
  └─ 生图：SD1.5 + 她的 LoRA（13 MB）
  ↓
数据：D:\QQrobot\*.json / chat_archive / diary / backup
```

---

## 二、分层

| 层 | 组件 | 职责 |
|---|---|---|
| **接入层** | SnowLuma `3000` | QQ 收发、mp3→silk、图片缓存 |
| **框架层** | AstrBot `6185` | 消息管线、LLM 调用、工具调度、分段回复 |
| **人格层** | `persona\whale-girl.md` → DB | 她是谁、怎么说话、底线 |
| **能力层** | 27 插件 + 32 工具 | 记忆、B站、联网、声音、生图、日记 |
| **数据层** | `D:\QQrobot\*.json*` | 长期/短期记忆、存档、心情、规则、词库 |
| **推理层** | WSL + GPU | 说话（CosyVoice3）、换声（RVC）、生图（SD+LoRA）|
| **运维层** | 控制台 `8765` + watchdog | 启停、状态、调音、故障重启 |

## 三、聊天链路

```
QQ 消息
  ↓ SnowLuma → AstrBot
  ├─ 1. 白名单 / 限流
  ├─ 2. 命令匹配（/日记 /兴趣 /上网 /画 /语音 …）
  ├─ 3. 模型路由（cost_router）
  │     ├─ force_flash=true → 全部 flash
  │     └─ 否则：≤16 字寒暄 → flash + 清空工具；其余 → pro + 按关键词裁工具
  ├─ 4. 注入（on_llm_request，全部写 system_prompt，不写历史）
  │     ├─ anime_kb        二次元词条（命中才注入）
  │     ├─ bili_pusher     【最近刷到的视频】+【最近往来】
  │     ├─ feedback_learner【主人额外要求的】
  │     ├─ group_memory    【你们最近聊过】
  │     ├─ mood            【今天的心情】
  │     ├─ interest        【你最近最感兴趣的话题】
  │     ├─ diary           【你昨天/今天写的日记】
  │     └─ slang_learn     【你最近在网上学的词】
  ├─ 5. LLM（v4-pro 或 flash，thinking 关闭）
  ├─ 6. 工具调用（需要时，最多 32 个工具）
  ├─ 7. on_decorating_result
  │     ├─ chat_archive    存原文
  │     ├─ chat_format     标点/换行规整 + 多行拆段
  │     ├─ sticker_sender  挑表情（文字发完补发）
  │     └─ voice_reply     判定要不要出声 → 扣字 → 转语音
  └─ 8. 分段回复（0.6–1.3 秒一段）
        ↓
QQ
```

### 格式规整（`tools\textnorm.py`，全局共用）

| 步骤 | 规则 |
|---|---|
| 1 | URL / Windows 路径 / 《标题》先保护 |
| 2 | 半角 `, . ? !` → 全角，**只贴在中文字符旁边**（英文、`12:30` 不动）|
| 3 | 连续标点收敛 |
| 4 | 中文之间空格 → 逗号 |
| 5 | 双换行 → 单换行 |
| 6 | 行尾：问句加 `？`、强情绪加 `！`、其余不加句号 |
| 7 | ≤120 字拆成多条消息段；>120 字整条不拆 |
| 8 | B站 评论走同一套（额外保留表情码空格、逗号 ≤4）|

## 四、B站链路（她自己去刷）

```
定时器（120±20 分钟，16–22 点）
  ↓ 推荐流 10 条候选
逐条判断（字幕 / 抽帧 / 探测音频 / 弹幕梗）
  ↓ deepseek-flash 判据
第一条「值得」的
  ↓ 写评论（3 次生成，全败则跳过 + 日报 + 当天提醒一次）
  ↓ 发表 → 2 秒复核
  ↓ 写回 bili_memory / 聊天存档 / 日报 / 时间线 / bili_activity
  ↓ 推 QQ（默认合并一条；`qq_split` 可拆）
     今天看了个视频，<内容概括>
     我觉得挺有意思的，<为什么感兴趣>
```

| 参数 | 值 |
|---|---|
| 模式 | `auto` / `dry` / `dm` |
| 间隔 | 120±20 分钟 |
| 活跃时段 | 16:00–22:00 |
| 推送层数 | `qq_layers: 2` |
| 失败策略 | 不发兜底文案 |

## 六、声音链路（本机 GPU）

```
文字
  ↓ AstrBot 插件 feiyu_voice（/肥鱼说话 或工具 feiyu_speak）
声音服务 9880（WSL，systemd 托管）
  ↓ 常驻 daemon（模型只加载一次；空闲 30 分钟退出）
CosyVoice3（两条声线 cute/gentle → 现在只留 cute + 情绪）
  ↓ 情绪：奶音 / 开心（指令 + WORLD 声码器后期）
24kHz WAV → SnowLuma 转 silk → QQ 语音
```

| 项 | 值 |
|---|---|
| 热态延迟 | 6–17 秒（看内存余量）|
| 冷启动 | 40–80 秒 |
| 显存 | 约 5.5 GB |
| 语速/停顿/起伏 | 0.9 / 0.12 / 0.32 / 0.35（可调）|
| RVC 换声 | 40kHz，4 分 42 秒素材约 44 秒 |

### 自动语音（`voice_reply`）

```
她回复完
  ├─ 你明确说「说句话」「让我听听」→ 必出
  ├─ 否则 5% 概率
  ├─ 限制：≤42 字、私聊、15 分钟冷却、日上限 10
  └─ 出语音时：扣住文字 → 发「…」→ 8~10 秒后语音 → 1.5 秒留白
     失败则把文字补发出去，不会失声
```

## 七、生图链路（阿里云百炼 API）

```
她判断该出图（或你说 /画 …）
  ↓ image_gen 插件（工具 draw_image）
阿里云百炼 qwen-image-2.0-pro（同步接口，12–14 秒）
  ↓ 提示词自动拼：蓝黑渐变长发 / 呆毛 / 鲸鳍耳 / 蓝瞳 / 白围裙女仆装 / 鲸尾
1024×1024 PNG → voice_out\gen\ → 作为 QQ 图片发出
```

| 项 | 值 |
|---|---|
| 模型 | `qwen-image-2.0-pro`（另有 `qwen-image-2.0`，5 秒、更便宜）|
| 接口 | `POST /api/v1/services/aigc/multimodal-generation/generation`（同步）|
| Key | `secrets\qwen_key.txt` |
| 出图 | 12–14 秒 / 1024×1024 |
| 成本 | 按张计费，约 0.1–0.5 元/张 |
| 配置 | `image_gen.json`：`provider` / `model` / `local_fallback` |

**本地 SD 已卸载**（2026-10-29）：anything-v5、IP-Adapter、训练集共释放约 8 GB。
只保留训练好的 LoRA（`models\whale-lora-chibi\`，13 MB）作为备份，需要时可重新装回本地通道。
